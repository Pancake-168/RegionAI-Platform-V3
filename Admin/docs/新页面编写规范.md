# 新页面编写规范

编写新页面之前**必读**本文档。它覆盖样式规则、组件复用、技术栈约束、环境适配和路由注册。

> 本规范以目标项目 `docs/UI规则与新建页面注意事项（必读）.md` 和 `docs/基础组件规范.md` 为唯一依据。
> 当前项目是目标 UI 的 **Vue 翻版**：除底层使用 Vue 3 + Reka UI 外，样式、交互、组件分区必须与目标项目完全一致。

---

## 一、UI 规则体系（三层架构）

本项目 UI 规则分为三层：**设计 Token 层 → 全局样式类层 → 组件层**。

### 第一层：设计 Token（`src/styles/variables.css`）

所有视觉属性通过 CSS 自定义属性定义。组件和页面**禁止写死颜色值、圆角、阴影**。

#### 暗色 Token（`:root` 默认）

```css
/* 背景 */
--bg: #0b0d11;
--bg-elev: #11141a;
--glass: rgba(255,255,255,0.05);
--glass-brd: rgba(255,255,255,0.08);

/* 文字 */
--text: #e6e9ef;
--muted: #9aa3b2;

/* 强调色（琥珀金） */
--accent: #fbbf24;
--accent-2: #fcd34d;
--accent-rgb: 251, 191, 36;

/* 功能域色 */
--color-system: #82aaff;
--color-job: #c792ea;
--color-agent: #ffcb6b;
--color-tool: #89ddff;
--color-success: #2fcb5b;
--color-warn: #ff9a69;
--color-error: #f07178;
--color-error-rgb: 240, 113, 120;

/* 间距 — 六级：xs(4px) sm(6px) md(8px) lg(12px) xl(16px) 2xl(24px) */
--spacing-xs / --spacing-sm / --spacing-md / --spacing-lg / --spacing-xl / --spacing-2xl

/* 圆角 — 五级：sm(6px) md(8px) lg(10px) xl(12px) full(9999px) */
--radius-sm / --radius-md / --radius-lg / --radius-xl / --radius-full

/* 字号 — 四级：xs(11px) sm(12px) base(13px) md(14px) */
--text-xs / --text-sm / --text-base / --text-md

/* 布局 */
--titlebar-height: 32px;
--sidebar-width: 48px;
--nav-height: 36px;

/* 字体 */
--font-sans: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;
--font-heading: '优设标题黑', system-ui, ...;
--font-mono: 'SFMono-Regular', Consolas, ...;

/* 输入控件 */
--input-bg: rgba(255,255,255,0.04);
--switch-track-bg: rgba(255,255,255,0.12);

/* 毛玻璃模糊值 — 三级 */
--blur-overlay: 4px;   /* Dialog 遮罩 */
--blur-panel: 10px;    /* .glass / Popover / DropdownMenu / Select / Toast */
--blur-tooltip: 12px;  /* Tooltip */
```

#### 亮色主题覆盖方式

亮色主题通过 `:root[data-theme='light']` 选择器覆盖颜色变量。**不需要写 `@media (prefers-color-scheme)`**，主题由 `useTheme()` composable 控制。

亮色核心值：

```css
:root[data-theme='light'] {
  --bg: #f7f8fa;
  --bg-elev: #ffffff;
  --glass: #ffffff;
  --glass-brd: rgba(0, 0, 0, 0.14);
  --text: #10151c;
  --muted: #5b6472;
  --accent: #fbbf24;
  --accent-2: #fcd34d;
  --accent-rgb: 217, 119, 6;
}
```

#### 固定主题 Token（不随亮暗切换）

以下 Token 只在 `:root` 定义，亮色不覆盖：

| Token                          | 值                       | 用途                                  |
| ------------------------------ | ------------------------ | ------------------------------------- |
| `--dialog-overlay-bg`          | `rgba(0,0,0,0.45)`       | Dialog 遮罩层（亮色下用更轻的覆盖值） |
| `--tooltip-bg`                 | `rgba(32,32,32,0.92)`    | Tooltip 背景                          |
| `--tooltip-text`               | `rgba(255,255,255,0.93)` | Tooltip 文字                          |
| `--tooltip-border`             | `rgba(255,255,255,0.12)` | Tooltip 边框                          |
| `--blur-overlay/panel/tooltip` | 4px/10px/12px            | 模糊值                                |

#### 自定义字体

项目中仅加载了一个自定义字体 `优设标题黑`（woff2 + ttf），对应 `--font-heading`。**禁止引入其他字体文件**。

### 第二层：全局样式类（`src/styles/index.css`）

已有结构的场景直接用全局类名。template 内**禁止任何形式的 `style=""` / `:style=""` 属性**，所有样式放在 `<style scoped>` 块内。`h()` 函数中动态创建 VNode 时允许 `style: { ... }` 传参。

#### 布局框架

```html
<div class="app-layout">
  <div class="main-page">
    <nav class="app-nav">...</nav>
    <div class="app-content">
      <!-- 你的页面内容 -->
    </div>
  </div>
</div>
```

`App.vue` 已提供外层容器。新页面渲染在 `<router-view />` 中（位于 `.app-content` 内），**不需要自己写外层布局容器**。

#### 按钮系统

```html
<button class="btn primary">主按钮</button>
<button class="btn secondary">次要按钮</button>
<button class="btn subtle">低调按钮</button>
<button class="btn danger">危险按钮</button>
<button class="btn primary spinning">加载中</button>
```

按钮 hover 规则：

- 统一 `translateY(-1px)` + 颜色/背景/边框变化
- **禁止外阴影、外发光**
- **不缩放**（不用 `scale`）

#### 其他全局类

| 类名                                                          | 用途                                                     |
| ------------------------------------------------------------- | -------------------------------------------------------- |
| `.glass`                                                      | 毛玻璃面板（`var(--glass)` + `blur(var(--blur-panel))`） |
| `.icon-btn`                                                   | 图标按钮（透明底 + hover 高亮）                          |
| `.pill.success` / `.pill.error` / `.pill.warn` / `.pill.info` | 状态标签                                                 |

#### 硬性约束

1. 组件 CSS 写在对应 `*.module.css` 中，只处理布局/定位/动画；颜色/圆角/阴影/模糊值**必须引用 `var(--xxx)`**
2. **绝对禁止写死颜色值、圆角、阴影、模糊值**
3. 需要新视觉属性时**先在 `variables.css` 定义**，且在 `:root` 和 `:root[data-theme='light']` 中分别定义；固定深色 Token 只放 `:root`
4. 复杂交互组件用 **Reka UI** 做骨架
5. 新通用组件放 `src/components/common/`，统一从 `index.ts` 导出；页面私有组件放页面目录内

#### 永久 UI 规则

1. **禁原生组件**：凡是能用 common 封装或 Reka 原语替代的原生控件，禁止直接写 `<button>`、`<label>`、`<input>`、`<select>`、`<textarea>`。只有 `Button`、`Input`、`Textarea` 这类底层控件封装本身才允许保留原生标签。
2. **border + 外发光禁止并存**：当元素已有 `border` 时，禁止再叠加外发光、泛光、模糊外边框、外 `box-shadow`。层次靠 `border` + 背景 + 间距表达；`box-shadow` 只允许内阴影（`inset`）。
3. **弹窗/浮层必须主题适配**：light 下不允许像 dark 一样昏暗；弹窗、浮层、面板在 light/dark 下必须有明确可辨的区分度与对比度。

#### 模糊值使用层次

| 场景                                                | Token            | 值   |
| --------------------------------------------------- | ---------------- | ---- |
| Dialog 遮罩层                                       | `--blur-overlay` | 4px  |
| `.glass`、Popover、DropdownMenu、Select 面板、Toast | `--blur-panel`   | 10px |
| Tooltip                                             | `--blur-tooltip` | 12px |

## 二、写新页面的完整检查清单

### 1. 外层容器和参考文件

**不需要自己写外层布局容器**。`App.vue` 已提供 `.app-layout` → `.main-page` → `.app-nav` + `.app-content`（`<router-view />`）。

先看关键参考文件：

- `src/views/DemoPage.vue` — 44 个组件的完整用法（`/demo` 路由）
- `src/components/common/index.ts` — 44 个组件导出清单
- 目标项目 `docs/基础组件规范.md` — 每个组件 props/API/样式基准

### 2. 样式规则（最重要）

- **颜色/圆角/阴影/模糊值绝不写死**。只能用 `var(--xxx)`
- **通用组件** CSS 写在对应 `*.module.css` 中
- **页面结构布局**用 `<style scoped>` 定义 class，模板用 `class="xxx"` 引用
- 页面私有子组件样式写在对应 `.vue` 文件的 `<style scoped>` 块内
- 简单场景直接用全局类：`.glass`、`.btn.*`、`.pill.*`、`.icon-btn`
- 需要新 Token 时在 `variables.css` 的 `:root` 和 `:root[data-theme='light']` 中分别定义，命名用语义（如 `--section-bg`），不描述实现（不用 `--blue-500`）

### 3. 组件复用

- 先查 `src/components/common/index.ts`，44 个组件应直接复用
- 新通用组件放 `src/components/common/`，从 `index.ts` 导出
- 页面私有组件放页面目录内

### 4. 技术栈约束

- **无 CSS 框架、无 Tailwind**。样式全靠 Token + `<style scoped>` / `*.module.css`
- 交互组件用 **Reka UI**（`reka-ui`），不手写弹窗/下拉/开关逻辑
- 图标用 `@iconify/vue`，已安装 `@iconify-json/codicon` 和 `@iconify-json/material-symbols`
- 路由用 `vue-router`
- **禁止引入其他图标库、CSS 框架、字体文件**

### 5. 环境适配

- 桌面端专用功能用 `isTauri()` 守卫
- 日志用 `createLogger(fileName, functionName)`，**禁止裸 `console.log`**
- 静态资源路径用 `import.meta.env.BASE_URL` 拼接，不写死 `/`

### 6. 代码风格

- 组件用 **PascalCase**（`MyPage.vue`），CSS 类名用 **camelCase**
- 类型定义不滥用 `any`，项目 TS 配置 `strict: true`
- 遵循 `.prettierrc.json`：单引号、分号、尾逗号、100 字符换行

### 7. 路由注册

在 `src/router/index.ts` 添加路由：

```ts
{
  path: '/my-page',
  name: 'MyPage',
  component: () => import('@/views/MyPage.vue'),
}
```

### 8. 主题适配

- 主题通过 `useTheme()` composable 管理，持久化到 `localStorage` key `pancake-theme`
- 首次访问（无 localStorage）默认**亮色**，与目标项目一致
- 通过 `document.documentElement` 的 `data-theme` 属性切换 CSS 变量
- 开发时需在亮/暗两种状态下测试页面效果
- 需要固定暗色时，进入时设置、离开时恢复

### 9. 页面结构模板

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { Icon } from '@iconify/vue'
import { createLogger } from '@/utils/logger'
import { Button, Input, toast } from '@/components/common'
// 按需导入 44 个组件中的任意组合

const log = createLogger('MyPage.vue', 'MyPage')
</script>

<template>
  <!-- 页面内容直接写，外层容器由 App.vue 提供 -->
  <div class="my-page-content">
    <!-- 你的内容 -->
  </div>
</template>
```
