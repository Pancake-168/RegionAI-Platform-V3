# 新页面编写规范

编写新页面之前**必读**本文档。它覆盖样式规则、组件复用、技术栈约束、环境适配和路由注册。

---

## 一、UI 规则体系（三层架构）

本项目 UI 规则分为三层：**设计 Token 层 → 全局样式类层 → 组件层**。

### 第一层：设计 Token（`src/styles/variables.css`）

所有视觉属性通过 CSS 自定义属性定义。组件和页面**禁止写死颜色值、圆角、阴影**。

#### 暗色 Token（`:root` 默认）

```css
/* 背景 */
--bg: #0b0d11;
--bg-elev: #11141a;
--glass: rgba(255,255,255,0.05);
--glass-brd: rgba(255,255,255,0.08);

/* 文字 */
--text: #e6e9ef;
--muted: #9aa3b2;

/* 强调色 */
--accent: #e2b04a;
--accent-2: #f0c060;
--accent-rgb: 226, 176, 74;

/* 功能域色 */
--color-system: #82aaff;
--color-job: #c792ea;
--color-agent: #ffcb6b;
--color-tool: #89ddff;
--color-success: #2fcb5b;
--color-warn: #ff9a69;
--color-error: #f07178;
--color-error-rgb: 240, 113, 120;

/* 间距 — 六级：xs(4px) sm(6px) md(8px) lg(12px) xl(16px) 2xl(24px) */
--spacing-xs / --spacing-sm / --spacing-md / --spacing-lg / --spacing-xl / --spacing-2xl

/* 圆角 — 五级：sm(6px) md(8px) lg(10px) xl(12px) full(9999px) */
--radius-sm / --radius-md / --radius-lg / --radius-xl / --radius-full

/* 字号 — 四级：xs(11px) sm(12px) base(13px) md(14px) */
--text-xs / --text-sm / --text-base / --text-md

/* 布局 */
--titlebar-height: 32px;
--sidebar-width: 48px;
--nav-height: 36px;

/* 字体 */
--font-sans: system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif;
--font-heading: '优设标题黑', system-ui, ...;
--font-mono: 'SFMono-Regular', Consolas, ...;

/* 毛玻璃模糊值 — 三级 */
--blur-overlay: 4px;   /* Dialog 遮罩 */
--blur-panel: 10px;    /* .glass / Popover / DropdownMenu / Select / Toast */
--blur-tooltip: 12px;  /* Tooltip */
```

#### 亮色主题覆盖方式

亮色主题通过 `:root[data-theme='light']` 选择器覆盖颜色变量。**不需要写 `@media (prefers-color-scheme)`**，主题由 `useTheme()` composable 控制。

#### 固定主题 Token（不随亮暗切换）

以下 Token 只在 `:root` 定义，亮色不覆盖：

| Token | 值 | 用途 |
|---|---|---|
| `--dialog-overlay-bg` | `rgba(0,0,0,0.45)` | Dialog 遮罩层 |
| `--tooltip-bg` | `rgba(32,32,32,0.92)` | Tooltip 背景 |
| `--tooltip-text` | `rgba(255,255,255,0.93)` | Tooltip 文字 |
| `--tooltip-border` | `rgba(255,255,255,0.12)` | Tooltip 边框 |
| `--blur-overlay/panel/tooltip` | 4px/10px/12px | 模糊值 |

#### 自定义字体

项目中仅加载了一个自定义字体 `优设标题黑`（woff2 + ttf），对应 `--font-heading`。**禁止引入其他字体文件**。

---

### 第二层：全局样式类（`src/styles/index.css`）

已有结构的场景直接用类名。简单布局/动态值用 `:style` 绑定 `var(--xxx)` Token 也是允许的（DemoPage 即采用此方式）。禁止的是 `:style` 中写死颜色值（如 `style="color: #fff"`）。

**规则**：`:style` 中的值必须是 `var(--xxx)` 引用或纯布局数值（如 `width: '260px'`），不能出现裸颜色/阴影/圆角值。样式常量抽取到 `<script setup>` 顶部（如 `const rowStyle = { display: 'flex', ... } as const`），避免模板中重复。**使用 `as const`** 确保类型兼容。**页面私有组件**用 `*.module.css`，结构布局用 `:style` + Token。

#### 布局框架

```html
<div class="app-layout">        <!-- 根容器 flex column, height:100vh -->
  <div class="main-page">       <!-- 主区域 flex:1, column, overflow:hidden -->
    <nav class="app-nav">...</nav>  <!-- 顶部导航 36px -->
    <div class="app-content">   <!-- 内容滚动区 flex:1, overflow:auto -->
      <!-- 你的页面内容 -->
    </div>
  </div>
</div>
```

`App.vue` 已提供外层容器。新页面渲染在 `<router-view />` 中（位于 `.app-content` 内），**不需要自己写外层布局容器**。

#### 按钮系统

```html
<button class="btn primary">主按钮</button>
<button class="btn secondary">次要按钮</button>
<button class="btn subtle">低调按钮</button>
<button class="btn danger">危险按钮</button>
<button class="btn primary spinning">加载中</button>  <!-- loading 态 -->
```

行为规则：hover → `translateY(-1px)` + 增强阴影（不缩放），active → 回弹，disabled → `opacity: 0.5`。

#### 其他全局类

| 类名 | 用途 |
|---|---|
| `.glass` | 毛玻璃面板（`var(--glass)` + `blur(var(--blur-panel))`） |
| `.icon-btn` | 图标按钮（透明底 + hover 高亮） |
| `.pill.success` / `.pill.error` / `.pill.warn` / `.pill.info` | 状态标签 |
| `input` / `textarea` / `select` | 表单元素已全局统一样式 |

### 第三层：组件规范

项目共有 **17 个通用组件**，统一从 `src/components/common/index.ts` 导出：

| # | 组件 | 用途 | Vue 依赖 | 调用注意 |
|---|------|------|----------|----------|
| §1 | Button | 按钮（loading/disabled 封装） | 无 | `<Button variant="primary">文字</Button>`；图标用 `#icon` slot |
| §2 | IconContainer | 统一图片/图标容器 | 无 | `src` 字符串=图片模式，默认 slot=组件模式 |
| §3 | Input | 单行文本输入 | 无 | `<Input v-model="val" />`；外层 `<div>` 设宽度 |
| §4 | Textarea | 多行文本输入 | 无 | `<Textarea v-model="val" />`；外层 `<div>` 设宽度 |
| §5 | Select | 下拉选择器 | Reka UI | `<Select v-model="val" :options="opts" />`；`SelectOption.icon` 接受 VNode |
| §6 | Switch | 开关 | Reka UI | `<Switch v-model="val" />` |
| §7 | Tooltip | 悬停提示 | Reka UI | `<Tooltip content="提示"><button>悬停</button></Tooltip>`；**默认 slot 只能有一个根元素** |
| §8 | Popover | 弹出卡片 | Reka UI | `<Popover><template #trigger><button>打开</button></template>内容</Popover>` |
| §9 | DropdownMenu | 下拉菜单 | Reka UI | `:trigger` prop 接收 **VNode**（`h()` 创建），不是 slot；`MenuItem.icon` 也是 VNode |
| §10 | ContextMenu | 右键菜单 | Reka UI | `<ContextMenu :items="items"><div>右键区域</div></ContextMenu>` |
| §11 | Dialog | 通用弹窗 | Reka UI | **无内置 trigger**，必须外部 `<Button @click="open=true">` + `:open` + `@update:open` |
| §12 | Confirm | Dialog 子集确认弹窗 | 基于 Dialog | `<Confirm :open="open" @update:open="..." @confirm="..." />` |
| §13 | Toast | 全局通知通道 | Reka UI | `toast('消息', 'success')` — 直接调用函数，不渲染组件 |
| §14 | Tabs | 标签页切换 | Reka UI | `TabItem.icon` 和 `TabItem.content` 是 **VNode**（`h()` 创建） |
| §15 | ScrollArea | 统一样式滚动区域 | Reka UI | `<ScrollArea :max-height="200">内容</ScrollArea>` |
| §16 | EmptyState | 空状态占位 | 无 | 图标用 `#icon` slot，操作按钮用 `#action` slot |
| §17 | Skeleton | 骨架屏 | 无 | `<Skeleton variant="text" :count="5" />` |

> **VNode 创建模式**：多个组件（DropdownMenu、Tabs、Select）的 icon/content/trigger 字段需要 VNode 而非字符串。使用 Vue 的 `h()` 函数：
> ```ts
> import { h } from 'vue'
> import { Icon } from '@iconify/vue'
> 
> // MenuItem icon
> const myIcon = h(Icon, { icon: 'codicon:edit', width: 14 })
> 
> // DropdownMenu trigger
> const myTrigger = h('button', { class: 'btn secondary' }, '打开菜单')
> 
> // TabItem content
> const myContent = h('p', { style: { color: 'var(--text)' } }, '内容文本')
> ```

完整用法见 `src/views/DemoPage.vue`（`/` 路由）。

#### 硬性约束

1. 组件 CSS 写在 `*.module.css`，只处理布局/定位/动画。颜色/圆角/阴影**必须引用 `var(--xxx)`**
2. **绝对禁止写死颜色值**（如 `#fff`、`rgba(0,0,0,0.1)`）
3. 需要新视觉属性时**先在 `variables.css` 定义**，且在 `:root` 和 `:root[data-theme='light']` 中分别定义
4. 复杂交互组件用 **Reka UI**（`reka-ui`）做骨架
5. 新通用组件放 `src/components/common/`，从 `index.ts` 导出；页面私有组件放页面目录内

## 二、写新页面的完整检查清单

### 1. 外层容器和参考文件

**不需要自己写外层布局容器**。`App.vue` 已提供 `.app-layout` → `.main-page` → `.app-nav` + `.app-content`（`<router-view />`）。

先看两个关键参考文件：
- `src/views/DemoPage.vue` — 所有 17 个组件的完整用法（`/` 路由）
- `src/components/common/index.ts` — 已有组件导出清单

### 2. 样式规则（最重要）

- **颜色/圆角/阴影绝不写死**。只能用 `var(--xxx)`，如 `var(--text)`、`var(--accent)`、`var(--radius-md)`
- **通用组件** CSS 写在 `*.module.css`，`<script setup>` 中 `import styles from './xxx.module.css'`，模板用 `:class="styles.xxx"`
- **页面结构布局**直接用 `:style` 绑定 `var(--xxx)` Token（参考 DemoPage：样式常量提取到 `<script setup>` 顶部，`as const` 确保类型兼容）
- **页面私有子组件**（如页面内的面板/卡片）用 `*.module.css`
- 简单场景直接用全局类：`.glass`、`.btn.*`、`.pill.*`、`.icon-btn`
- 需要新 Token 时在 `variables.css` 的 `:root` 和 `:root[data-theme='light']` 中分别定义，命名用语义（如 `--section-bg`），不描述实现（不用 `--blue-500`）

### 3. 组件复用

- 先查 `src/components/common/index.ts`，17 个组件应直接复用
- 新通用组件放 `src/components/common/`，从 `index.ts` 导出
- 页面私有组件放页面目录内

### 4. 技术栈约束

- **无 CSS 框架、无 Tailwind**。样式全靠 Token + module.css
- 交互组件用 **Reka UI**（`reka-ui`），不手写弹窗/下拉/开关逻辑
- 图标用 `@iconify/vue`，已安装 `@iconify-json/codicon`（VS Code 图标集，对应前缀 `codicon:`）和 `@iconify-json/material-symbols`（Material 图标集，对应前缀 `material-symbols:`）
  ```vue
  <script setup>
  import { Icon } from '@iconify/vue'
  </script>
  <template>
    <Icon icon="codicon:add" :width="14" />
    <Icon icon="codicon:close" :width="16" />
    <Icon icon="material-symbols:dark-mode" :width="18" />
  </template>
  ```
- 路由用 `vue-router` 的 `createWebHistory`（History 模式，无 `#` 的干净 URL）
- **禁止引入其他图标库、CSS 框架、字体文件**

### 5. 环境适配

- 桌面端专用功能用 `isTauri()` 守卫：
  ```ts
  import { isTauri } from '@/utils/isTauri'
  if (isTauri()) { /* Tauri 桌面端逻辑 */ }
  ```
- 日志用 `createLogger(fileName, functionName)`，**禁止裸 `console.log`**：
  ```ts
  import { createLogger } from '@/utils/logger'

  // createLogger 按函数粒度创建，第一个参数是文件名，第二个是函数名
  const log = createLogger('MyPage.vue', 'handleSubmit')
  log.debug('调试信息', detail)
  log.info('提交成功', { id: 123 })
  log.warn('响应超时，正在重试')
  log.error('提交失败', error)
  ```
  日志体系说明：
  - **Transport 模式**：所有日志输出到控制台（开发可见），Tauri 桌面端额外通过 IPC 桥接到 Rust 后端写入文件
  - `registerTauriTransport()` 和 `registerGlobalErrorHandlers()` 已在 `main.ts` 中调用，新页面无需关心初始化
  - Tauri 桌面端日志位置：开发模式 `%TEMP%/regionaiv3/logs/`，生产模式安装目录 `data/logs/`
  - 日志按天轮转，旧文件自动重命名为 `regionai.app.log.YYYY-MM-DD`
  - `createLogger` 的两个参数会写入日志前缀 `[RegionAI:文件名:函数名]`，方便定位问题来源
- 静态资源路径用 `import.meta.env.BASE_URL` 拼接，不写死 `/`

### 6. 代码风格

- 组件用 **PascalCase**（`MyPage.vue`），CSS 类名用 **camelCase**
- 类型定义不滥用 `any`，项目 TS 配置 `strict: true`
- 遵循 `.prettierrc.json`：单引号、分号、尾逗号、100 字符换行

### 7. 路由注册

在 `src/router/index.ts` 添加路由：
```ts
{
  path: '/my-page',
  name: 'MyPage',
  component: () => import('@/views/MyPage.vue'),
}
```

### 8. 主题适配

- 主题通过 `useTheme()` composable 管理（`src/composables/useTheme.ts`），持久化到 `localStorage` key `pancake-theme`
- 首次访问（无 localStorage）默认**暗色**
- 通过 `document.documentElement` 的 `data-theme` 属性切换 CSS 变量
- 开发时需在亮/暗两种状态下测试页面效果
- 如需固定暗色（像首页那样），进入时设置、离开时恢复：
  ```ts
  import { useTheme } from '@/composables/useTheme'
  const { theme } = useTheme()
  const previousTheme = theme.value
  onMounted(() => { theme.value = 'dark' })
  onUnmounted(() => { theme.value = previousTheme })
  ```

```vue
import { Icon } from '@iconify/vue'

</script>

<template>
  <!-- 页面内容直接写，外层容器由 App.vue 提供 -->
  <div :style="{ padding: 'var(--spacing-xl)' }">
    <!-- 你的内容 -->
  </div>
</template>
```
