# 路由模式切换：Hash → History

## 背景

上级要求路由格式为 `/chat` 而非 `/#/chat`。当前项目使用 `createWebHashHistory`，所有路由 URL 带 `#`。

## 变更

| 文件                     | 修改                                                                    |
| ------------------------ | ----------------------------------------------------------------------- |
| `src/router/index.ts`    | `createWebHashHistory()` → `createWebHistory(import.meta.env.BASE_URL)` |
| `docs/新页面编写规范.md` | 路由章节同步更新                                                        |

## 影响分析

- **浏览器 dev server**：零影响，Vite 自带 SPA fallback，`/chat` 直接可用
- **Tauri 桌面端**：生产模式 `lib.rs:130` 使用 `WebviewUrl::App("index.html")`，初始加载后 Vue Router 接管全部导航，正常使用不涉及服务端路由。若将来有页面内刷新或深度链接需求，需在 Rust 侧配置 SPA fallback
- **Nginx 部署**：需配置 `try_files $uri /index.html`

## 不改的文件

- 所有现有 `.vue` 组件、路由配置、页面逻辑均不受影响

## 验证

- `npm run dev` 后浏览器访问 `http://localhost:1420/` → DemoPage 正常
- `npm run build` 零错误
